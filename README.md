# Radio_Hitz

A central library for organizing radio programs, historical broadcasts, playlists, and My Media automation.

Audio recordings remain on the local drive; this repository holds indexes, playlists, documentation, and automation scripts. Do not commit copyrighted recordings or private local file paths.

## Media category indexes

The categories below correspond to folders under `D:\BU\MyMedia\Recordings`. Local inventories are generated by `Check_MyMediaInv.ps1` and may be copied into the repository's `Catalog/` directory after review.

<!-- MEDIA-CATEGORIES:START -->
| Category | Local recordings folder | Catalog |
| --- | --- | --- |
| OTR | `OTR` | `Catalog/OTR/` |
| Speeches | `Speeches` | `Catalog/Speeches/` |
| Sermons | `Sermons` | `Catalog/Sermons/` |

**Updating:** Run `Check_MyMediaInv.ps1 -Execute` locally after changing recordings. Review its generated README and CSV files, then copy approved indexes into `Catalog/` and commit/push to GitHub. The GitHub workflow refreshes the separate radio-show directory from `Catalog/RadioShows.csv`; it does not scan local recordings.

## Refresh the index

- **GitHub:** Actions > Update Radio Index > Run workflow. This refreshes show listings without accessing your local recordings.
- **Local:** Run `./PowerShell/Utilities/Update-RadioIndex.ps1 -MediaRoot 'D:\MyMedia\Radio-Shows'` to count files, then commit and push README.md.
- **Automatic:** Changes to `Catalog/RadioShows.csv` trigger the GitHub workflow to regenerate the directory.

See [setup documentation](Documentation/Setup.md).
